Estación Telegráfica Interactiva (SEC-08)Repositorio oficial del proyecto de desarrollo de software y esquemas electrónicos para una estación telegráfica interactiva orientada al entrenamiento y transmisión en código Morse.1. Descripción del ProyectoLa estación telegráfica es un dispositivo hardware/software concebido para la práctica, decodificación y simulación de transmisiones en código Morse. El sistema integra una interfaz física de control basada en pulsadores y potenciómetros, un microcontrolador Arduino Uno para el procesamiento de señales y comunicación Serial bidireccional en tiempo real.2. Componentes de HardwareEl sistema se compone de los siguientes elementos electrónicos:Microcontrolador: Arduino Uno (ATMega328P).Pulsador Principal: Botón Arcade de $\varnothing 32\text{ mm}$ (microswitch con terminales COM, NO y NC).Pulsador Secundario: Botón táctil mecánico SX28 ($1.5 \times 1.5\text{ cm}$).Control Analógico: Potenciómetro Slider B103 ($10\text{ k}\Omega$, dimensiones $7.5 \times 1\text{ cm}$).Placa de Distribución: Placa preperforada PCB de $5 \times 7\text{ cm}$.3. Puesta en Marcha y ConexiónCableado Físico: Conectar los componentes a la placa PCB y al Arduino Uno siguiendo estrictamente la tabla de ruteo de pines.Carga de Firmware: Compilar y subir el código de control al Arduino Uno asegurando la lectura por puerto Serial (9600 baudios).
